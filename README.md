# MiraMoney — Frontend веб-приложение для трансграничных денежных переводов

Современный, производительный и полностью адаптивный frontend-сервис международных денежных переводов **MiraMoney**, разработанный в 100% строгом Pixel-Perfect соответствии с дизайн-макетом Figma ([Transgran_v1](https://www.figma.com/design/nsdTgXzFHs4Ng2KG5jBpBO/Transgran_v1?node-id=0-1)).

---

## 🚀 Стек технологий

- **Фреймворк**: [Next.js 15](https://nextjs.org/) (App Router, Server & Client Components)
- **Библиотека UI**: React 19
- **Язык**: TypeScript (строгая типизация)
- **Стилизация**: Tailwind CSS (полная палитра дизайн-токенов из Figma)
- **Иконки**: Lucide React + векторные и растровые ассеты из Figma

---

## 🔌 Готовность к интеграции с API (No Hardcode)

Проект изначально спроектирован по стандартам коммерческой разработки с четким разделением слоев UI, бизнес-логики и сетевого взаимодействия. В кодовой базе **полностью отсутствует hardcode данных**.

### 1. Архитектура интеграции с бэкендом
В проекте реализован единый сервисный слой API-клиента ([`src/services/api.ts`](./src/services/api.ts)), который автоматически:
1. Выполняет реальные HTTP-запросы при указании переменной окружения `NEXT_PUBLIC_API_BASE_URL`.
2. Использует типобезопасные фикстуры из [`src/data/mockData.ts`](./src/data/mockData.ts) при работе в автономном режиме без поднятого сервера.

### 2. Спецификация API-эндпоинтов

| Метод клиента в `src/services/api.ts` | HTTP Endpoint | Описание |
|---|---|---|
| `getSupportedCurrencies()` | `GET /currencies` | Список поддерживаемых валют и флагов |
| `getCountryDirections()` | `GET /directions` | Список стран с актуальными курсами и лимитами |
| `calculateTransfer(countryId, amount)` | `POST /transfers/calculate` | Расчет суммы получения, комиссии и фиксация курса |
| `createTransfer(payload)` | `POST /transfers` | Создание и отправка заявки на перевод |
| `getUserProfile()` | `GET /user/profile` | Получение профиля авторизованного пользователя |
| `getTransactionsHistory(filters)` | `GET /transfers/history` | История переводов с поддержкой фильтров |
| `getLegalDocuments()` | `GET /documents` | Тексты правовых документов для раздела «Документы» |
| `getFAQList()` | `GET /faq` | Справочные вопросы и ответы (FAQ) |
| `getReviewsList()` | `GET /reviews` | Отзывы клиентов |

### 3. Подключение бэкенда через `.env.local`
Для подключения готового бэкенда достаточно создать файл `.env.local` на основе [`.env.example`](./.env.example):
```env
NEXT_PUBLIC_APP_URL=http://localhost:3000
NEXT_PUBLIC_API_BASE_URL=https://api.miramoney.ru/v1
```

### 4. Строгие контракты данных ([`src/types/index.ts`](./src/types/index.ts))
Все модели данных полностью задокументированы и типизированы:
- `Currency` — код, символ, наименование, иконка.
- `CountryDirection` — страна, курс, лимиты (min/max), способы выплаты, банки.
- `TransferCalculation` — сумма отправления, валюта, курс, комиссия, сумма к зачислению.
- `UserAccount` — профиль, статус KYC-верификации, подтвержденные контакты.
- `TransactionRecord` — запись об операции (дата, суммы, статус, реквизиты).
- `LegalDocument` — статьи правовых соглашений.

## 📦 Быстрый старт и запуск

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск в режиме разработки
```bash
npm run dev
```
Приложение будет доступно по адресу [http://localhost:3000](http://localhost:3000).

### 3. Сборка для production
```bash
npm run build
npm run start
```

## 🎨 Реализованные сценарии и экраны

1. **Главная страница (Landing Page)**:
   - Интерактивный двунаправленный калькулятор перевода с мгновенным пересчетом.
   - Фирменный попап выбора валюты (модалка Desktop `#107:208` / Bottom Sheet Mobile `#107:812`).
   - Направления перевода с актуальными курсами валют.
   - Интерактивный FAQ-аккордеон и отзывы.

2. **Пошаговый сценарий перевода денег (`/transfer`)**:
   - **Шаг 1**: Выбор направления, суммы и валюты.
   - **Шаг 2**: Выбор банка получателя (табы: *Все*, *На карту*, *По телефону*).
   - **Шаг 3**: Ввод реквизитов (номер телефона получателя, имя и фамилия латиницей).
   - **Шаг 4**: Выбор банка списания отправителя.
   - **Шаг 5**: Проверка деталей перевода, фиксация курса и таймер обратного отсчета.
   - **Шаг 6**: Статус обработки и подтверждение создания заявки.

3. **Личный кабинет пользователя (`/dashboard`)**:
   - **Профиль**: личные данные, статус верификации и быстрые ссылки.
   - **История переводов**: десктопная таблица / мобильные карточки + детальный просмотр заявки с возможностью повтора.
   - **Верификация**: пошаговый процесс и зона загрузки документов.
   - **Лимиты**: лимиты для резидентов и нерезидентов.
   - **Безопасность**: 2FA, активные сессии и соглашение.
   - **Настройки**: выбор валюты по умолчанию через попап, язык, переключатели уведомлений.
   - **Документы**: список документов со статьями.
   - **Поддержка**: круглосуточные контакты.
